# Changelog

## 0.1.0 (2026-11-26)


### ⚠ BREAKING CHANGES

* the container listens on 6066. Update the port mapping (`6066:6066`, or `3000:6066` to keep the published port), health checks and reverse proxy targets, or set PORT=3000 to keep the old port.
* **discover:** saved search rows are dropped from Discover; recreate them in Settings → General → Discover as filtered rows.
* the Podcasts search tab, podcast requests and the podcast settings (default library and folder, approval policy) are gone. Existing podcast requests, if any, are no longer handled.
